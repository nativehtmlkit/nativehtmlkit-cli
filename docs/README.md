# NativeHTMLKit CLI documentation

[CLI research and draft IDL](CLI-Spec/README.md) are preserved as implementation input, **not evidence of a released CLI**. The final CLI command reference and acceptance evidence should be added only after the executable exists and has been verified.

**Binding decision changed after the research:** CLI is independently implemented in `nativehtmlkit-cli`, not first as a crate in Core. Project and this repository's `AGENTS.md` override early research pages that suggest otherwise. `nativehtmlkit` is the canonical executable and `nhk` its shortcut.
